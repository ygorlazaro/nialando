# ADR-0001: Estado, saves e versionamento do gerador

Data: 2026-10-30
Status: Aceito

## Contexto

O estado do jogo precisa ser:
- **Serializável** em formato versionado (arquivo, não banco de dados no MVP).
- **Determinístico**: mesma seed + mesmos parâmetros + mesmas ordens ⇒ mesmo resultado.
- **Estável**: IDs inteiros estáveis, sem `Guid.NewGuid()`, sem referências cíclicas entre objetos.
- **Migrável**: quando o algoritmo do gerador mudar, o save pode ser rejeitado ou migrado.

O repositório anterior usava PostgreSQL via EF Core e `Guid` em tudo; isso é descartado.

## Decisão

1. **Saves** são arquivos JSON (`System.Text.Json` com source generators) na pasta de dados do usuário
   (`user://` do Godot; em headless, via `Path.Combine` com `Environment.GetFolderPath(SpecialFolder.LocalApplicationData)`
   ou XDG `~/.local/share`). Nunca caminhos fixos.
2. **Formato do save** contém:
   - `saveVersion` (versão do formato de save)
   - `generatorVersion` (versão do gerador de mapa que produziu o estado)
   - `seed` (long)
   - `params` (parâmetros do jogo)
   - `state` (grafo de dados serializável)
3. **IDs**: inteiros estáveis (`int`/`uint`), gerados sequencialmente pelo gerador a partir do PRNG.
   Proibido na Simulation: `Guid.NewGuid()`, `System.Random`, `DateTime.Now`, `GetHashCode()`,
   iteração sobre coleções de ordem indefinida.
4. **Autosave** a cada turno, múltiplos slots. Sem `BinaryFormatter`. Sem banco de dados no MVP
   (SQLite só se aprovado depois).
5. **GeneratorVersion** é incrementado (Major) quando o algoritmo de geração muda de forma incompatível.
   O save guarda `generatorVersion`; ao carregar, se for menor que o atual, o save é rejeitado
   (ou migrado por uma rotina explícita).

## Consequências

- A Simulation é a fonte de verdade; a UI nunca altera o estado diretamente.
- Testes de "golden hash": para seeds fixas, o hash do estado serializado deve bater com um valor
  versionado no repositório. Rodam no CI Linux agora e no CI Windows depois.
- `GameSession` (fachada) é a única porta de entrada para o estado.

## Aberta

- Formato: `System.Text.Json` com source generators, ou `MessagePack` se aprovado.
- Compressão (gzip) em saves — a definir quando houver saves grandes.
