# ADR-0002: i18n — mensagens como dados estruturados

Data: 2026-10-30 (mantida do repositório anterior)
Status: Aceito

## Contexto

O jogo precisa de mensagens que registram o que aconteceu entre os turnos,
com suporte a múltiplos idiomas no futuro (pt-BR, Esperanto, inglês).

## Decisão

- **Mensagem = dado estruturado**: `chave` + `parâmetros` + `entidades envolvidas` (clicáveis).
- **Não se usa texto pronto** na Simulation. A UI renderiza a mensagem via localização
  (arquivo de tradução mapeia `chave` → `template` com `{placeholders}`).
- Isso mantém a simulação determinística (sem strings soltas) e o i18n simples.

## Consequências

- A Simulation emite `Message` objects; a camada de apresentação os traduz.
- Arquivos de localização em `data/i18n/` (JSON), um por idioma.
- Chaves são estáveis (não mudam entre versões); se mudarem, migrar as mensagens antigas.
